# ALAN-4AI · el agente que crea agentes (v1.0)

ALAN es un agente para Claude Code que construye otros agentes: le cuentas tu idea en una o dos frases, te entrevista hasta entenderla y te entrega el agente listo en una carpeta. También mejora agentes que ya tienes.

- **Qué hay aquí:** la carpeta `ALAN-4AI/` es el contenido del ZIP `ALAN-4AI_v1.0_alumnos.zip` de la lección 44, sin cambios. Su base de conocimiento viene incluida en `ALAN-4AI/kb/`.
- **Cómo instalarlo y usarlo:** sigue la hoja de la lección 44 del curso Arquitectos de IA, «Instala y usa a ALAN, el creador de agentes» (en Skool). Si no la tienes, empieza por `ALAN-4AI/README.md` y `ALAN-4AI/GUIA_DE_DESPLIEGUE.md`.
- **Atajo:** abre Claude Code dentro de la carpeta `ALAN-4AI` y salúdalo; él te pregunta si quieres crear (Modo A) o mejorar (Modo B) un agente.
- **Requisitos:** Claude Code y tu plan de Claude (Pro o Max). No necesitas claves de API; las de `.env.local.example` son opcionales.
