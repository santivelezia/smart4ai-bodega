## Cómo instalar el marketplace

- **Claude Code:** `claude plugin marketplace add santivelezia/smart4ai-plugins` y luego `claude plugin install radar-tienda@smart4ai-plugins`.
- **claude.ai y Cowork:** Configuración → Personalizar → Plugins → Agregar → Agregar marketplace → Agregar desde un repositorio → `santivelezia/smart4ai-plugins`.

Los artefactos se abren con tu cuenta de claude.ai.
